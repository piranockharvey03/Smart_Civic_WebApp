## System Overview

The Smart Civic Platform is a comprehensive issue reporting and tracking system designed for Kampala Capital City Authority (KCCA). It enables citizens to report civic service issues, receive ticket numbers, and track progress from submission through resolution.

### Key Features

- **Issue Reporting**: Submit civic issues with detailed descriptions, photos, and GPS coordinates
- **Ticket Tracking**: Monitor issue status using unique ticket numbers
- **Location Mapping**: Interactive maps for precise issue location identification
- **Department Routing**: Automatic routing to appropriate KCCA departments
- **Staff Assignment**: Efficient assignment of issues to qualified staff members
- **Progress Monitoring**: Real-time status updates and notifications
- **Analytics Dashboard**: Comprehensive reporting and performance metrics
- **Mobile Responsive**: Accessible from any device with internet connectivity

### Issue Categories

The platform supports the following issue categories:

1. **Roads** - Potholes, damaged pavement, road markings, traffic signs
2. **Garbage** - Waste accumulation, illegal dumping, missed collections
3. **Drainage** - Blocked drains, flooding, sewer issues
4. **Water** - Water leaks, pipe bursts, water quality issues
5. **Streetlights** - Broken or malfunctioning street lighting
6. **Security** - Public safety concerns, broken streetlights in dark areas
7. **Other** - Any other civic service issues not covered above

### Issue Status Workflow

Issues progress through the following stages:

1. **Submitted** - Initial submission by citizen
2. **Under Review** - Initial assessment by department
3. **Assigned** - Assigned to specific staff member
4. **In Progress** - Active work being performed
5. **Pending** - Awaiting additional information or resources
6. **Resolved** - Issue has been addressed
7. **Closed** - Resolution verified and case closed
8. **Reopened** - Issue reopened if resolution was insufficient

### Priority Levels

- **Critical** - Emergency situations requiring immediate attention
- **High** - Urgent issues affecting public safety or major services
- **Medium** - Standard priority issues
- **Low** - Minor issues with minimal impact

## Citizen User Guide

### Overview

Citizens are the primary users who report civic issues and track their resolution progress. This guide covers all citizen-specific features.

### Registration

1. Navigate to the registration page
2. Fill in the required information:
   - Full Name
   - Email Address
   - Phone Number (optional)
   - Division/Location
   - Password
3. Click "Register" to create your account
4. You will receive a confirmation email

### Login

1. Navigate to the citizen login page
2. Enter your email address and password
3. Click "Login"
4. You will be redirected to your citizen dashboard

### Dashboard Features

The citizen dashboard provides:

- **Personal Statistics**: Total issues, open issues, pending issues, resolved issues
- **Recent Reports**: Latest issues you've submitted with current status
- **Staff Responses**: Latest replies from KCCA staff
- **Notifications**: Updates about your submitted issues
- **Profile Summary**: Your account information

### Reporting an Issue

#### Step-by-Step Process

1. **Access Report Form**
   - Click "Submit New Issue" from your dashboard
   - Or navigate directly to the report issue page

2. **Fill in Issue Details**
   - **Category**: Select the appropriate issue category from the dropdown
   - **Division**: Select your division/location
   - **Title**: Provide a clear, concise title describing the issue
   - **Description**: Provide detailed information about the issue:
     - What happened
     - Exact location
     - Nearby landmarks
     - When it started
     - Impact on the community

3. **Location Information**
   - **Location Details**: Enter street name, landmark, ward, or block
   - **Address/Landmark**: Optional address captured from map
   - **GPS Coordinates**: Use the interactive map to capture precise location:
     - Click "Use my location" to use your device's GPS
     - Or click on the map to place the pin manually
     - Search for a location using the search box

4. **Photo Evidence**
   - Upload a clear photo showing the issue
   - Accepted formats: JPG, PNG, GIF, WEBP
   - Maximum file size: 5 MB
   - Ensure the photo clearly shows the problem

5. **Submit**
   - Review all information
   - Click "Submit Issue"
   - You will receive a ticket number (e.g., KCCA-2026-0001)
   - Save this ticket number for tracking

#### Submission Tips

- Use a clear title that explains the problem quickly
- Include landmarks so KCCA can locate the issue accurately
- Upload one clear photo showing the problem
- Provide as much detail as possible in the description
- Use the generated ticket number to follow up later

### Viewing Your Issues

1. Navigate to "View My Reports" from your dashboard
2. You will see a list of all issues you've submitted
3. Each issue shows:
   - Ticket number
   - Title
   - Category
   - Location
   - Current status
   - Priority level
4. Click on any issue to view detailed information

### Tracking Issue Progress

#### Using Your Account

1. Login to your citizen account
2. Navigate to "View My Reports"
3. Click on the issue you want to track
4. View the timeline of all activities and updates

#### Public Tracking (Without Login)

1. Navigate to the "Track Issue" page
2. Enter your ticket number
3. Enter the email address used when reporting
4. Click "Look Up Ticket"
5. View current status and recent activity

### Understanding Issue Status

- **Submitted**: Your issue has been received and is awaiting review
- **Under Review**: KCCA is assessing the issue
- **Assigned**: The issue has been assigned to a staff member
- **In Progress**: Work is being done to resolve the issue
- **Pending**: Awaiting additional information or resources
- **Resolved**: The issue has been addressed
- **Closed**: The resolution has been verified
- **Reopened**: The issue has been reopened if resolution was insufficient

### Adding Comments

1. Open the issue you want to comment on
2. Scroll to the comments section
3. Type your comment in the text box
4. Click "Submit Comment"
5. Your comment will be visible to staff and administrators

### Managing Your Profile

1. Navigate to your profile from the dashboard
2. Update your information:
   - Full Name
   - Email Address
   - Phone Number
   - Division/Location
   - Address
   - Ward
3. Click "Save Changes" to update your profile

### Notifications

You will receive notifications for:

- Status changes on your issues
- Comments from staff
- Assignment of your issues to staff
- Resolution of your issues

View all notifications from the notifications section of your dashboard.

### Best Practices for Citizens

- **Be Specific**: Provide detailed descriptions and precise locations
- **Use Photos**: Upload clear photos that show the issue clearly
- **One Issue Per Report**: Report each issue separately for better tracking
- **Follow Up**: Use your ticket number to track progress
- **Be Patient**: Some issues take time to resolve depending on complexity
- **Provide Updates**: If the situation changes, add comments to update staff

1. Open the issue you want to update
2. Locate the status update section

1. Open the issue you want to comment on

3. Type your update or response

- **Critical**: Emergency situations requiring immediate attention
- **High**: Urgent issues affecting public safety
- **Medium**: Standard priority issues
- **Low**: Minor issues

Use the issue console filters to:

- View specific status types (submitted, in progress, resolved, etc.)

- Filter by category
- Filter by date range
- Search by ticket number or keyword

### Workload Management

Monitor your workload through:

- **Assigned Tickets**: Total number of issues assigned to you
- **Active Tasks**: Issues currently in progress
- **Pending Tasks**: Issues awaiting action
- **Resolved Tasks**: Issues you have completed

### Communication with Citizens

- **Be Professional**: Maintain professional and courteous communication
- **Be Clear**: Provide clear, concise updates
- **Be Timely**: Respond to citizen comments promptly
- **Be Transparent**: Explain delays or complications honestly
- **Be Helpful**: Provide guidance on what citizens can expect

### Using the Issue Map

1. Navigate to the Issue Map from your dashboard
2. View all issues plotted on an interactive map
3. Filter by status, priority, or category
4. Click on markers to view issue details
5. Use heatmap view to identify problem areas

### Best Practices for Staff

- **Update Regularly**: Keep issue status current to inform citizens
- **Document Actions**: Log all actions taken on issues
- **Communicate**: Keep citizens informed of progress
- **Prioritize**: Focus on critical and high-priority issues
- **Collaborate**: Coordinate with other staff on complex issues

## Issue Management Workflow

### Complete Issue Lifecycle

#### 1. Issue Submission

- Citizen submits issue through the report form
- System generates unique ticket number
- Issue is assigned "Submitted" status
- Citizen receives confirmation with ticket number

#### 2. Initial Review

- Department manager or admin reviews submitted issue
- Issue is categorized and prioritized
- Issue is assigned to appropriate department
- Status changes to "Under Review"

#### 3. Staff Assignment

- Department manager assigns issue to staff member
- Staff member receives notification
- Status changes to "Assigned"

#### 4. Work in Progress

- Staff member begins work on issue
- Status changes to "In Progress"
- Staff adds updates and comments
- Citizen receives progress notifications

#### 5. Completion

- Staff member completes work
- Status changes to "Resolved"
- Staff adds resolution notes
- Citizen receives completion notification

#### 6. Verification

- Citizen or admin verifies resolution
- If satisfactory, status changes to "Closed"
- If not satisfactory, status changes to "Reopened"
- Reopened issues return to step 4

### Status Change Rules

- **Submitted → Under Review**: Only department managers or admins
- **Under Review → Assigned**: Only department managers or admins
- **Assigned → In Progress**: Only assigned staff member
- **In Progress → Pending**: Assigned staff or department manager
- **Pending → In Progress**: Assigned staff or department manager
- **In Progress → Resolved**: Only assigned staff member
- **Resolved → Closed**: Admin or citizen (if they reported it)
- **Closed → Reopened**: Admin or citizen (if they reported it)
- **Any Status → Any Status**: Admins can change any status

### Priority Assignment

- **Automatic**: System assigns initial priority based on category
- **Manual Override**: Department managers and admins can adjust priority
- **Priority Escalation**: Issues can be escalated based on time or severity

### Notification Triggers

System sends notifications for:

- Issue submission (to citizen)
- Status changes (to citizen and assigned staff)
- Staff assignment (to staff member)
- Comments added (to relevant parties)
- Issue resolution (to citizen)
- Issue closure (to citizen)
- Issue reopening (to assigned staff)

## Troubleshooting

### Common Issues and Solutions

#### Login Problems

**Problem**: Cannot login to the system

**Solutions**:
- Verify you are using the correct login URL for your role
- Check that caps lock is not on
- Ensure you are using the correct email address
- Reset your password if you've forgotten it
- Contact administrator if account is locked

**Problem**: Account locked after multiple failed attempts

**Solutions**:
